Neither has an official trending-products API, so either can break silently if Amazon changes its layout. Flipkart/Meesho/Myntra/Snapdeal are currently disabled (config.ENABLED_SOURCES) after confirming they're blocked even from cloud IPs — their tables above simply won't appear while disabled. "Picks" scoring is a heuristic (bestseller rank + Google Trends token overlap), gated by the 13-KPI rubric judged per-candidate by a real LLM (Cerebras primary, Gemini as a secondary check) — there is no keyword-approximation fallback; a candidate neither provider can judge is excluded entirely rather than scored approximately. The Alibaba/AliExpress columns only confirm a matching listing exists and shares words with the query — not price, MOQ, or seller reliability, so vet a supplier manually before committing.
